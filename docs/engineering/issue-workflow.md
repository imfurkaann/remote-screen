# Issue Workflow

## Bug Intake Standard

All bug tickets must include a completed triage section based on:

- `.github/agents/bug-triage-template.md`

## Required Fields

1. Reproduction steps
2. Expected vs actual behavior
3. Scope and impact
4. Root cause hypothesis
5. Fix proposal and risk
6. Regression tests added

## Enforcement

- No bug ticket can be marked resolved without triage details.
- Regression gate evidence is required before closing.
