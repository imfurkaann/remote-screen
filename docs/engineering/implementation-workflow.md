# Implementation Workflow

## Error Management Adoption

All implementation and bug-fix work must follow:

- `.github/agents/error-management-playbook.md`

## Required RIFG Cycle

1. Reproduce
2. Isolate
3. Fix
4. Guard

## Completion Criteria

- Regression checklist passed (`.github/agents/regression-gate-checklist.md`)
- Test evidence attached under `tests/reports/YYYY-MM-DD/`
- Phase gate status updated in checklist
