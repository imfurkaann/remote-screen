# Pilot Blocker Bug List

Date: 2026-04-01

## Usage

Use this list for blockers discovered during the pilot window. Every item must include reproduction steps, impact, and an owner.

## Fields

- Bug ID
- Title
- Environment
- Reproduction steps
- Expected vs actual behavior
- Impact level
- Owner
- Status
- Regression test link

## Status Values

- Open
- In progress
- Fixed in staging
- Verified in pilot
- Waived

## Closure Rule

- A blocker can close only after the fix is verified in the same pilot path or formally waived by the pilot owner.
