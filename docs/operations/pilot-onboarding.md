# Pilot Onboarding Guide

Date: 2026-04-01

## Purpose

This guide standardizes the first pilot customer onboarding so the team can repeat the process for the next account.

## Onboarding Checklist

1. Confirm the pilot tenant and success owner.
2. Verify staging and production separation rules.
3. Create or confirm screen hardware inventory.
4. Pair each screen using the approved device flow.
5. Publish the first playlist and verify playback.
6. Confirm notification and escalation contacts.
7. Review command and telemetry expectations with the pilot owner.

## Day 0 Expectations

- The customer knows who owns content updates.
- The customer knows how to report playback or command issues.
- The internal team knows who is on point for triage.

## First Week Check-In

- Review online/offline screen counts.
- Review command completion and timeout rates.
- Review playlist publish and sync timing.
- Record any blockers in the pilot blocker list.

## Support Rules

- Escalate critical issues through the incident runbook.
- Track pilot-specific issues separately from product bugs.
- Do not widen scope during the first pilot unless there is explicit approval.
